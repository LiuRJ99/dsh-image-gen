# Proposal: 画廊展示排序、分类筛选与多视图模式支持 (Gallery View Enhancement)

## Why

当前 `dsh-image-gen` 插件的画廊（Gallery）页面仅支持单一的固定网格视图（Grid View），且只能按创建时间倒序展示，筛选维度也仅限于简单的引擎下拉选择和 Prompt 模糊匹配。

在实际使用中，用户产生大量生成图片后，存在以下痛点：
1. **排序单一**：无法按创建时间升序（最早在前）、Prompt 字母排序、文件大小等进行灵活排序。
2. **分类与筛选受限**：仅有单一下拉框，缺少可视化的分类标签（带数量 Badge）、图片比例/尺寸等实用维度的筛选。
3. **展现方式无法调节**：仅有固定 1:1 裁剪的大网格卡片，在需要对比提示词、查看图片精确分辨率/体积、批量浏览元数据时，缺乏**列表视图 (List View)** 和 **表格视图 (Table View)**。

本次优化旨在全面增强画廊的展示与管理体验，补齐多维度排序、分类筛选、多视图模式切换（网格 / 列表 / 表格）以及本地偏好持久化。

---

## What Changes

- **多模式排序 (Sorting)**：
  - 支持「时间降序（最新优先，默认）」、「时间升序（最早优先）」、「Prompt A→Z」、「Prompt Z→A」、「文件体积降序」。
  - 排序规则支持保存至 `localStorage`。
- **多维度分类与筛选 (Categorization & Filtering)**：
  - 引擎分类改为直观的分段/标签栏（All 全部 / GPT Image 2 / Gemini Image / 未知引擎），并动态展示各分类图片数量 Badge。
  - 增加图片比例/尺寸筛选器（全部 / 1:1 / 16:9 / 9:16 / 4:3 / 3:2 / 2:3 等）。
  - 优化 Prompt 搜索框交互（支持一键清空与实时过滤）。
- **多视图模式切换 (View Mode: Grid / List / Table)**：
  - 顶部工具栏提供视图模式切换按钮组：
    - **网格视图 (Grid)**：视觉优先的卡片瀑布网格，悬浮快捷操作。
    - **列表视图 (List)**：图文横向卡片列表，展示完整 Prompt、引擎/模型、分辨率、生成时间、文件大小与右侧操作栏。
    - **表格视图 (Table)**：紧凑明细表格，支持批量信息快速扫读与操作。
  - 视图模式自动保存至 `localStorage`，刷新后自动恢复。
- **元数据展示与国际化 (i18n)**：
  - 格式化展示时间、图片分辨率（如 `1024×1024`）、文件大小（如 `1.2 MB`）。
  - 完善中英文双语字典（`DICT`）。

---

## Capabilities

### New Capabilities
- `gallery-multi-view-and-sorting`: 为画廊提供排序控制（时间/名称/大小）、分类与比例筛选、网格/列表/表格多视图切换以及偏好持久化。

---

## Impact

- 影响前端文件：`src/client/gallery-view.tsx`、`src/client/index.tsx` (CSS 样式)、`src/client/gallery-store.ts`。
- **完全兼容**：不改动 IndexedDB 底层存储结构，无需数据库迁移；不改动后端生图服务与 DSH 附件管理机制。
- 新增/更新单测以覆盖内存排序、过滤逻辑与元数据格式化。
