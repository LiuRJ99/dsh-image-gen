## Purpose

为 `dsh-image-gen` 插件的画廊（Gallery）提供多模式排序、分类/比例筛选、网格/列表/表格多视图展现模式切换及偏好持久化。

---

## Requirements

### Requirement: 画廊支持多维度排序

画廊组件 SHALL 支持多种排序模式，并在前端过滤结果集后进行即时排序。排序模式 MUST 包含：
- 创建时间倒序（最新在前，默认）
- 创建时间升序（最早在前）
- Prompt 字典序升序（A→Z）
- Prompt 字典序降序（Z→A）
- 文件大小降序（大文件在前）

#### Scenario: 默认按时间倒序
- **WHEN** 用户首次打开画廊
- **THEN** 图片列表默认按 `createdAt` 降序排列，最新生成的图片位于最上方/最前列。

#### Scenario: 切换为 Prompt A-Z 排序
- **WHEN** 用户在排序选择器中选择「Prompt A→Z」
- **THEN** 画廊列表即时根据 prompt 的拼音/字母升序重新排列。

---

### Requirement: 画廊支持分类与比例筛选

画廊组件 SHALL 提供直观的分类与多维度筛选能力：
- 引擎分类分段标签栏（全部 / GPT Image 2 / Gemini Image / 未知引擎），显示各分类当前数量；
- 图片比例筛选（全部 / 1:1 / 16:9 / 9:16 / 4:3 / 3:4 / 3:2 / 2:3 等）；
- Prompt 关键词实时模糊匹配。

#### Scenario: 引擎分类切换
- **WHEN** 用户点击「Gemini Image」分类标签
- **THEN** 列表仅显示 Gemini 生成的图片，且标签上显示匹配的图片总数。

#### Scenario: 比例筛选
- **WHEN** 用户选择比例为「16:9」
- **THEN** 列表仅保留宽高比为 16:9 的图片。

---

### Requirement: 画廊支持网格、列表与表格多视图模式切换

画廊组件 SHALL 提供 **网格视图 (Grid)**、**列表视图 (List)** 与 **表格视图 (Table)** 3 种展现方式，且支持通过工具栏一键切换：
- **网格视图**：展示大缩略图网格卡片，悬浮提供快捷操作；
- **列表视图**：展示图文横向卡片列表，包含缩略图、完整 Prompt、生成时间、引擎/模型标签、分辨率尺寸、文件体积和右侧快捷操作栏；
- **表格视图**：展示紧凑表格明细，包含各列信息及操作列。

#### Scenario: 切换为列表视图
- **WHEN** 用户点击工具栏的「列表视图」图标
- **THEN** 画廊无缝切换为图文卡片列表布局，显示完整 Prompt 和所有元数据字段。

#### Scenario: 切换为表格视图
- **WHEN** 用户点击工具栏的「表格视图」图标
- **THEN** 画廊以结构化表格呈现所有生成记录。

---

### Requirement: 画廊偏好状态持久化

画廊组件 SHALL 将用户选中的「展现方式（网格/列表/表格）」与「排序模式」保存至 `localStorage`。

#### Scenario: 刷新后恢复用户偏好
- **WHEN** 用户将视图模式设为「列表视图」，排序设为「最早优先」，然后刷新页面或重新进入画廊
- **THEN** 画廊自动恢复为「列表视图」和「最早优先」状态。
